# Strona – Usługi Transportowo-Sprzętowe Snopek Sylwester

Landing page dla firmy tescia. Zawiera usługi, galerię sprzętu, obszar działania i kontakt.

## Co jeszcze trzeba uzupełnić

1. **Numer telefonu** – zamień `XXX XXX XXX` i `+48XXXYYYYYY` na prawdziwy numer w pliku `index.html` (3 miejsca: nagłówek, przycisk hero, kontakt).
2. **E-mail** – jeśli chcesz, możesz dodać adres w sekcji Kontakt.
3. **Adres firmy** – opcjonalnie w stopce lub w schema.org.

## Jak uruchomić lokalnie

Otwórz `index.html` w przeglądarce lub uruchom prosty serwer:

```bash
cd snopek
python3 -m http.server 8000
```

Potem wejdź na: http://localhost:8000

## Jak hostować

- **Netlify** lub **Vercel** – przeciągnij folder do ich interfejsu (darmowy hosting).
- **GitHub Pages** – wrzuć repo i włącz Pages w ustawieniach.

## Edycja treści

Otwórz `index.html` w edytorze i edytuj tekst. Możesz też poprosić Cursora (AI), np.:
- „zmień numer telefonu na 123 456 789”
- „dodaj nową miejscowość do obszaru działania”
